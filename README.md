# C++ Mini Projects

This repository contains practical C++ mini projects developed to understand core programming concepts and Object-Oriented Programming (OOP).

## Topics Covered
- C++ Basics and Control Structures
- Functions and Modular Programming
- Object-Oriented Programming (OOP)
- Classes and Objects
- Inheritance and Polymorphism
- File Handling
- Menu-Driven Programs

## Purpose
To gain hands-on experience with C++ programming concepts as part of academic laboratory work and to strengthen logical problem-solving skills.
